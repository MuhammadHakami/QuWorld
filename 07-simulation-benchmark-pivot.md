# Pivot: Prove "Adding Qubits Improves Simulation Performance"

Direction change (user, 2026-07-27): instead of only measuring physical-consistency drift inside frozen world models ([[00-overview]]), **challenge open simulation benchmarks head-on** with the hybrid system. Claim to prove: **adding qubits to a parameter-matched classical surrogate improves simulation accuracy**, with the mechanism story that **neutral-atom analog hardware natively adapts its Hamiltonian to the simulation state** (input-conditioned detunings, trainable atom geometry — the analog block is a learned physical co-processor).

The frozen-world-model adapter track ([[02-architecture]], [[03-pipeline]]) is **not discarded** — it becomes the transfer story once benchmark wins exist. The Rydberg-generator ansatz carries over unchanged.

**Update 2026-07-27 (user directive):** the headline system uses a **ready frozen world model from Ant Group — LingBot-World v2 14B causal-fast — integrated with 30 simulated qubits**. Hook spec traced from code: [paper/lingbot_hook_spec.md](paper/lingbot_hook_spec.md). "30 simulated qubits" ladder: mr30 = 3×10q product register (trainable now, hardware-honest), entangled 30q via bounded-χ MPS next, exact 30q statevector inference-only (8.6 GB state — measured untrainable). The FNO sprint loop below remains the cheap hypothesis filter that selects the ansatz before it is promoted into the LingBot adapter.
